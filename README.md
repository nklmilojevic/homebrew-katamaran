# homebrew-katamaran

Homebrew tap for [katamaran](https://github.com/nklmilojevic/katamaran).

## Install

```sh
brew install --cask nklmilojevic/katamaran/katamaran
```

Or tap first:

```sh
brew tap nklmilojevic/katamaran
brew install --cask katamaran
```

## Requirements

- Apple silicon Mac (M1 or later)
- macOS 15 (Sequoia) or later
